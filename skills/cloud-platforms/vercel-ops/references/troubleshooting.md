# 故障定位

| 现象 | 下一步 |
|---|---|
| MCP OAuth 失效 | 本 skill 不依赖 MCP；单独 verify API token，不要求重新登录 MCP |
| 401 | token 已失效或错误；不打印 token，使用用户现有凭据入口更新 |
| 403 | 检查 team scope、token 权限、资源归属与套餐 |
| 配置/profile 不存在 | 修正显式路径或 profile；不能自动换到另一个账号 |
| 404 | 检查资源 ID 与官方 endpoint；不要用写请求轮流探测地址 |
| 429 | GET 有有限重试；批量降低频率，写请求按实际远程状态决定重跑 |
| 网络失败/超时 | 每请求 30 秒；检查实际网络。写请求可能已成功，先查远程状态 |
| 部署 ERROR/CANCELED | 保存本次 ID，读取该部署构建日志，非零退出 |
| 等待超时 | 查询同一 ID，不另建部署，也不把旧 READY 当成功 |
| JSON 管道失败 | 本地脚本 --json 输出单文档；官方 vercel logs --json 是 JSON Lines |
| 环境变量导入中断 | 校验完整输入；已成功项保留，修正错误后 upsert 重跑 |
| env list 没 value | 刻意移除密钥，清单不承担明文备份 |
| 构建日志为空 | 核对部署 ID 与时间范围；请求/函数运行日志应使用 vercel logs |
| 域名 verify 失败 | 以项目实际返回的验证记录为准，检查 DNS；不要硬编码历史 IP |
| CLI 命令/选项不存在 | 查本机 --help 与官方文档，不自动安装最新版 |
| Webhook 创建失败 | 先检查 webhooks list 和预留的 secret-file；网络失败可能已创建远程资源 |

`--verbose` 只输出方法和路径，不打印认证头、查询参数、请求体或错误响应体。
HTTP 详细错误可能含敏感值，本脚本仅报告状态码；需要深查时在安全环境处理响应。
通用 api、构建日志与官方 CLI 输出仍可能包含应用自身写出的敏感信息，回报前过滤。
