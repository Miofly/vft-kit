# 文献检索、综述与引用

## 检索与筛选

把问题拆成研究对象、主题、方法、政策/时代背景，先搜完整题名，再组合中英文同义词。选择互补数据库；中文教育研究可用知网、万方、维普、国家哲学社会科学文献中心、学校机构库和出版社原站，政策用政府原文。国际文献按学科选 ERIC、OpenAlex、Crossref、PubMed 等；普通网页搜索只是补充，不冒充数据库检索。

记录每个平台的检索日期、完整检索式、时间范围、结果数量、实际读取数量、纳入/排除规则和无法访问的部分。按 DOI 去重，无 DOI 时联合题名、作者、年份判断；不同版本和题名冲突保留关联，不能仅凭文件名合并。

先看题名和摘要，再阅读全文，提取研究问题、对象/样本、情境、方法、结果、局限及可支持论点。按主题综合相同与相反证据，区分证据质量和相关程度。不凭 DOI、搜索排名或被引数判质量，不把别的学科效果直接推广到本学科。

只有遵循可复现方案、系统筛选和相应报告规范时才称系统综述；普通毕业论文综述不能自动套 PRISMA 或编造筛选流程。元分析须有可比数据、效应量和恰当方法，不能用“多篇认为有效”代替定量合成。

## 引用证据表

规模小时用现有表格即可，至少区分：

| 字段 | 含义 |
|---|---|
| source_id | 稳定的内部编号，不随引用排序变化 |
| 题名、作者、年份、载体 | 以出版方、原文或可信数据库核验，冲突保留 |
| DOI/稳定地址、访问日期 | DOI 不是全文存在或质量保证 |
| 全文与阅读状态 | 仅记录 / 仅摘要 / 全文已取得 / 全文已阅读 |
| 支持论点与定位 | 页码、章节、表号或原文段落；必须真的支持该主张 |
| 局限与证据类型 | 实验、调查、案例、观点、政策、设计示例等 |

二手转引优先回查原始文献；无法取得时按学校要求明确转引，不假装读过原文。找不到的引文保留待核实标记，不能生成看似真实的作者和出版信息。

## 下载核验

1. 先从出版社/机构库页面定位全文，保留文章页与文件链接。OJS 的 view 地址可能是预览，也可能直接返回 PDF，以实际响应为准；需要时再取页面中的 download 链接。
2. 只用合法公开全文或用户已有访问权限；登录、验证码、购买、对外上传按宿主授权规则处理，不绕付费墙、不代点确认订阅。
3. 每次下载检查响应内容、大小与实际格式。`.pdf` 后缀、HTTP 200 或命令成功都不能排除 HTML 错误页。
4. 有工具时检查 `%PDF-`、运行 `pdfinfo`，用 `pdftotext` 或 PDF 读取工具核对首页题名、作者、年份、页数；扫描件没有文本层须明确需要 OCR，不能误判为空文档。散列查重复，文件名按实际题名修正。
5. 建下载清单，逐篇列成功/失败与原因；重试先看是否已成功，错误页面不计入全文数量。

## 格式与事实核验

先判断学校/期刊要求的引用体例和版本，再用用户指定或已有引用工具格式化；例如 GB/T 7714 的具体版本不能凭记忆固定。格式化不等于事实已核实。

DOI 无法解析、预览与 PDF 题名不同、在线年与印刷年不同，均记录来源冲突并回查，不能静默挑一个。正式定稿检查文内每条引用有文后条目，每条文后条目在正文被使用；编号随正文顺序更新，不能只排序文后表。
