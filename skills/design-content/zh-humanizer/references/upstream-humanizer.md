## 采纳

| 上游机制 | 中文落地 |
|---|---|
| Voice：先读作者样稿 | 只借用词、标点与转接习惯；不借事实，不新增第一人称反应 |
| File / Embedded mode | 文件只改正文，保护代码、链接、元数据与数据；嵌入任务只交所需正文 |
| Draft → audit → final | 扩充已有复扫：检查整篇句式、每节结尾和读者上下文；内部迭代，不额外交中间稿 |
| §18 简单系词 | 新增第 40 条；只有语义等价时才改成“是、有”，不把用途写成身份 |
| §25 文档元叙述 | 新增第 41 条；清理制作旁白，保留来源、方法限制、核实状态与迁移说明 |
| §26 错认读者 | 新增第 42 条；明确回复且有上下文才处理重复背景，调序须授权，不删新事实 |
| §23 知识缺口 | 补强第 38 条；区分模型截止声明与事实时点，不把缺资料推成隐私选择或确定事实 |
| When not to act | 保留真实插话、自我修正、复杂感受、圈层语与正式信件称呼落款；形式特征不是诊断器 |

翻案、戏剧碎片、伪格言、铺垫、假想敌、三连、破折号、模糊归因、宣传腔、加粗和标题复述等，现有 39 条已经覆盖，不重复增加规则。

## 不迁移

- 上游允许补写作者可能有的反应，本 skill 不采纳。作者情绪、动机与经历只能来自素材。
- 上游部分示例会删除来源不明的主张、媒体名单或粉丝数字。本 skill 默认是保真编辑，不是事实核查；保留归因与主张，不能以去 AI 味为由丢信息。
- 上游回复示例会省去诊断证据。本 skill 不据此删新数字、风险、承诺或行动依据；只去完全重复和无命题成分。
- 不把英文词表、连字符、弯引号或主动语态偏好直接变成中文禁令。中文引号、被动句和正常列举可保持原样。
- 不照搬“见到前五种模式就改”的强度排序；仍需区分真实纠错、原作者叙述、有意修辞和空架子。
- 不将上下文判断加入 banned-patterns.txt。正则无法可靠识别声口、用途、资料缺口与重复背景，不能扩大机械误杀。

## 评测边界

沿用冻结核心与留出集，不根据留出题调整规则。新增整体任务覆盖声口、文件保护、回复调序、资料缺口，并修正旧周报题判据与“不动结构”的冲突。静态校验和污染扫描不能证明写作质量提升；2026-10-10 的盲评成绩只属于旧版本，新版本需独立重跑。
