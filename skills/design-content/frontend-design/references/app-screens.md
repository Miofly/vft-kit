# 应用界面：工作台、后台、设置与数据页

方法改写自 Taste Skill（Leonxlnx/taste-skill，MIT，见 ../THIRD_PARTY_NOTICES.md）的 App screens 章节，按本地规则取舍。

## 适用与优先级

- 适用：仪表盘、后台管理、分析报表、设置计费、收件箱/队列/筛选列表、钱包、构建器、单对象详情页。
- 项目已有组件库/设计系统（VFT、shadcn 等）与业务规范优先，本文数值只在其未规定时作默认。
- 原文固定审美偏好（禁某字体、紫/靛色、强制数量）降为默认建议，不作硬性禁令。
- 用真实业务数据与状态，不画灰条假后台，不用 lorem/Acme/张三式占位。
- 不需要安装任何库；图表用项目已有组件或手写 SVG，按第 5 节配置，不用库默认样式。

## 流程

1. **盘点**：对象与字段单位、真实量级、谁用多久、最常见的下一步任务、产品名称/工作区/人。写小数据集，合计由行算出，一致性用 `console.assert`。
2. **一个问题**：一行写出屏幕首先回答什么，再写今天最该注意的“发现”，放标题下并紧挨相关操作；每个区块回答一个后续问题，答不了就删。
3. **选风格**：按使用方式（久用/扫一眼、团队/个人）选并写理由；定一个产品面孔（如品牌色落在主数据）和一个专属元素。
4. **外壳**：先搭空框（侧栏、顶栏、画布、标题行），在 1440 与 390 看；栅格算式写进注释。
5. **数据**：区块与图表都从数据集渲染，数字按 6 节格式化，标签用行业用语。
6. **状态**：每块的空/零/加载/错误，每行每控件的 hover/选中/focus/禁用。
7. **检查**：1440/768/390 截图，按第 13 节逐条回答，修最重 3 处，最多 3 轮。
8. **报告**：风格及理由、面孔与专属元素、每屏的问题、放过的检查、需替换为真实数据的样例清单。

动效只作反馈（按压、hover、展开、新行到达），不做入场动画。

## 1. 数据与首屏

- 同一事实出现两次是一个变量，文案和图表注释都从它生成。
- 合计按显示的四舍五入值相加；变化量 = 屏上两值之差。
- 相对数字写明基准（“比上周日早 45 分钟”），不写裸“+5”。
- 小数字保持小，不写虚荣总数，一周的账户不写“+12%”。
- 1440×900 首屏露出需求点名的每个区块标题与前几行；主区块高 200–360px，长列表截到 4–6 行 +“查看全部”，时效块（到期、超时、失败部署）排在长表前。
- 最大区块、最大数字回答那个问题；最常做的操作一键可达；证据放答案旁（“峰值 3.9%，23:28 部署后，已回滚”）。
- 外壳顶部有产品标志和名称，作用域用切换器或面包屑；标签用行业词（“等待客户回复”），不用“条目/记录”。

## 2. 外壳

| 原型 | 要点 |
| --- | --- |
| 开放平面 | 带字侧栏与页面同底，无分隔或 1px 线；无顶栏；边距 24–64px 或居中列 |
| 浅框 + 白纸 | 侧栏顶栏同一浅底 #f6f6f6–#f9fbfc；白纸距右下 8px，圆角 10–16，1px #eaeaea 边，无阴影 |
| 线分 T 形 | 210–240px 侧栏 + 64px 顶栏同底，1px 线分隔；切换器在顶栏右端；多用于深色 |
| 图标栏 | 宽 50–60px，图标 15–18px，间距 34–49px，省约 180px |
| 无侧栏 | 46–48px 顶栏 + 居中 1088–1208px 列；适合报表与少目的地产品 |

- 深色全局同一底，1px #161616–#232323 线分隔。
- **侧栏**宽 224–240px（210–292）；行点击区 32px、行距 34px；图标 16px 线性；标签 14px/400。
- **当前项**：浅色用中性灰胶囊（#e9e9e9–#ededed，圆角 8）；深色只提亮文字 #bbb→#fff。
- 分组标签 12–13px 灰色不全大写；设置、帮助放底部。导航计数只在待处理队列且名词清楚（“申请 5”）。导航项是其他页面而非本页锚点；目的地 ≤5 才用图标栏，且每图标有 tooltip 与无障碍名。
- **顶栏**默认不要；要则装搜索/切换器/对象名，高 44–51px 或 64px（带线）；居中搜索约 548×32。
- **右栏** `grid-template-columns: 1fr 384px`，间距 24px，与第一张卡顶对齐，只放稳定次要流。悬浮按钮仅限唯一主操作且不遮内容。

## 3. 画布、标题、筛选

- 流式边距 17–64px（常用 24、36–40），内容 1120–1312px；居中数据页 1100–1250px；标题顶偏移约 36px（20–88）。
- 一个间距值横纵通用。从标题到末行共用左右边线；栅格求和闭合（3×372+2×17=1152、12×77+11×16=1100）。
- 列数由条目数定（4 个 KPI 用 4 列），孤卡跨列。同行卡片底边对齐：先按内容平衡，否则堆叠或短卡顶对齐、只把“查看全部”/合计钉底；图例紧跟图表。卡内空白带 >40px 即空洞。
- ≤5 列的表或 ≤6 行的列表约 760px 宽，与下一块并排，不铺满。
- **h1** 每屏一个，常用 24px/600–700（18–32）；或面包屑末项作 h1（16px）。用名词，问候只给个人/团队首页，不加 emoji。副行 14–16px 灰色写数据（发现、时段、范围），不写“本页展示……”。
- 标题右侧只放真实操作或新鲜度戳（“更新于 16:09”+ 刷新）。每屏一个主按钮，近黑 #1d1f20 或深色反白，也可品牌色。
- 日期范围放页面级或卡片级之一。下划线标签页下有通宽 1px 线、指示条 2px；分段控件按选项宽。筛选行控件 32/36px，左范围右工具，到第一卡约 24px。

## 4. KPI 与 delta

- 默认一个容器用 1px 竖线分等宽列；或把主数字放进解释它的卡片。每行 3–4 个（1–6），数量等于列数。
- 数值常用 24px（16–40，独立卡约 30），不到 48；标签 14px 灰色在上，数值约为标签 1.7 倍；粗体只给金额。
- 不加彩色圆底图标、迷你折线、染色卡；单位作小号灰色后缀（24px 配 14px）。
- 答案数字（余额、净资产）30–36px，≥兄弟数字 1.3 倍，全屏最大。同一数字不在图例重复。
- KPI 兼作图表标签页：选中项 2px 线或激活底 + 墨色；未选项标签灰但数值仍为墨色。
- **Delta** 可选，10–15px 不大于标签，写明窗口（“较前 30 天”），只给数字上色或整体灰。
- **颜色表示好坏不表示涨跌**：延迟、错误率、成本、流失下降为好；坏方向用 `--negative`，好方向 `--positive` 或灰。
- 零变化或无法比较为灰：前期为 0 写“+4（新）”，无基准用灰色短横；不出现“↑100%”“>999%”、红色 0.00%、绿色 +0。

## 5. 图表

| 问题 | 形式 |
| --- | --- |
| 随时间变化 | 单折线；面积填充 ≤15% |
| 每期多少 | 直角柱 |
| 排名 | 排序横条列表 |
| 占比 | 细环或 2px 接缝 100% 堆叠条，≤5 份 |
| 离目标多远 | 进度条，两端标注，真实比例 |
| 计划用量 | 计划长轨道：已花实填、已承诺浅段、超支越界用负色 |
| 偏离目标 | 每项一行当前条 + 目标处 1px 刻度（子弹图） |
| 流向 | 零线上下双向柱，同刻度，轴两侧注明 |
| 每期与累计 | 两图并排等宽同日期，每屏至多一组 |

- 只有几个数就不画图；只有一个事件的平坦序列至多 2/3 宽、约 140px 高；预测段用虚线并标终值。
- 一图一系列（最多 3），其他指标用切换控件。绘图区高约 195px（112–264），宽高比 1.8–5.2。
- 网格只横向 3–5 条，1px 实线，浅 #e5e5e5、深 #2b2b2b；无 y 轴线，基线最重。
- y 刻度约 5 个，12px 灰色；整齐步长，顶刻度高于最大值，柱从 0 起；必须有刻度。
- x 标签 4–8 个，水平不旋转，首尾收进绘图区，同一步长到底；时间用时间刻度。
- 线 2px 直线段，不平滑不加点；多不填充，要填则平涂约 14%。柱直角或顶部 ≤4px 圆角。
- 每图一个色相；强调色放在主数据（今天、当前期、越界项），不放次要图或 delta。同一对象全屏同色，全屏 ≤4 色相。状态色只表状态。
- 单系列无图例；否则 ≤5 项，置卡片标题处（5–8px 点 + 12–14px 灰字）或做成带数值的表。
- 环图仅 3–5 份且旁边未列出，无扇区标签，细描边（90–154px 环用 3–5px）。进度条约 8px 全圆角，0 时无残段。
- 超常约 3 倍的跳变加 1px 标记 + 12px 原因标签；参考线 1px 虚线、标签在末端；标签不互撞不压线。空/短历史如实画零线与空期。

## 6. 表格与列表

- **行高**：单行常用 45px（36–53）；带媒体两行常用 72（媒体高 + 24–32）；卡内键值 21–32。第二行小一号灰色，两行标签行距 ≥40–44px。概览列表 2–5 行。
- **表头** 12px 常规灰色句首大写，不全大写，无底色带，多无下线（有则为表内最强线）；高 36–40px；数字列表头右对齐；只在当前排序列显示排序符号。
- **分隔**：不用斑马纹；行线 1px，比表面深 3–7%（#ededed–#f4f4f4），或靠行距/2–8px 间隙。
- **数字**右对齐 + `font-variant-numeric: tabular-nums`（确认字体支持）。金额 2 位、百分比 1–2 位、计数 0 位；千分位；只在容量行缩写（“12.7k / 20.0k”）；变化必带符号；货币符号后无空格。
- 标识列占 1/3–1/2 宽且桌面不截断。行内右对齐数字同一右边线；两个度量叠在同一单元格（计数上、灰色百分比下）。
- 只有标识和关键数字用主墨色；缺失为灰色短横，真零照常显示；收入绿色带“+”，支出墨色，不把每个负数标红；链接色只在名称格。
- **状态 pill** 高约 20px，文字 11–14px/500；浅底同色相深字（#dcfae5/#04250e、#ffedea/#831c1e）。饱和填充白字只给少见的待操作（超过约 1/5 行就改浅色对或 6px 圆点）。每行一个状态标记，chip 不换行不挤压。
- **操作与分页**：概览不分页，截断 +“查看全部”并写总数；完整列表页表头吸顶、显示区间（“1–50 / 1,284”）。行操作多数不需要，有则最右一个 kebab；需处理的行用固定尾列幽灵按钮或墨色文字，不用浅灰字。只有批量操作才放复选框。hover/选中用 1px 描边不改底色；驱动详情窗的列表选中行用 `--active` 底色。

## 7. 表单、设置与按钮

- 标签在上 14px/500，间距 8–10px；不用浮动标签或 placeholder 代标签。表单输入 38–40px（圆角 8–10），筛选控件约 32px，同场景同高。输入框白底 1px #e5e7eb 边，下拉边框深一级 #d1d5db。
- 说明到首个标签 24px，字段间 16px，到保存 16px。开关 28×16–33×20，开启色为语义绿或近黑。禁用仍可读并说明原因。
- **设置布局**：每节左标签列约 450px（16/500 标题 + 14px 灰说明）、右面板约 700px（#fafafa、圆角 16、内边距 16、无边无影）；节间通宽 1px 线上下各 32px。
- 危险操作放最后单独一节，负色文字/描边按钮，写后果，确认框点名对象。多个设置领域各一视图（h1 为领域名），不做一长页加锚点。每视图一种保存模型：即改即存显示“已保存”，或每面板右下一个保存。
- **按钮**高 32–34px（27–40）；紧凑风格圆角 6–8，柔和风格全胶囊；每屏一个填充主按钮（通常近黑），次按钮白底 1px 边，三级为文字；同行同高。

## 8. 字体与配色

- 一种无衬线 grotesk；第二字体只担一职（等宽用于数字或 ID，衬线用于一句问候）。h1 18–32px，数字不到 48px。
- 字号：标题 24、KPI 24、卡片标题 16（500–600）、正文/导航/单元格 14、标签/元信息/刻度 12、pill 11–12（下限 11）。每屏约 6 个字号（如 12/14/16/24）、3 种字重，700 每屏只用于一处。句首大写，字距 0；14px 行高 20，16px 行高 24。
- **浅色**：白卡 + 浅灰底，或白底灰面板；线分三级（卡片边、行线浅一级、控件边深一级）；承载文字的每级灰（含 placeholder）对背景 ≥4.5:1；强调色只给数据或只给操作，不出两套强调色系；侧栏不用深色/饱和色。
- **深色**：纯中性黑灰底，不用藏青/石板蓝；表面靠亮一级或 1px 线分层，可交互描边更亮（#373737–#4c4c4c）；最多两种灰；导航当前项靠亮度；强调色为绿时 `--positive` 就用它；彩色像素 ≤3%。
- **表面**：边框或阴影二选一，真阴影只给浮层（菜单、popover、对话框）。圆角两极：紧凑 4–8px 或柔和 16–24px，控件跟随，嵌套递减，≤3 种。
- **图标**线性一套，导航 16px、行内 12–14px，灰色，不放饱和色圆底。**间距** 4px 基准：卡片间 16、卡内 20、区块间 24–64。

## 9. 密度

| 档位 | 数据点 | 场景 | 参数 |
| --- | --- | --- | --- |
| 稀疏 | 6–25 | 首页、设置、单对象 | 内边距 20–24，行 56–92，正文 14–16 |
| 中等 | 25–50 | 分析概览、财务、列表 | 行 44–56，内边距 16–24 |
| 密集 | ~120 | 监控、研究 | 正文 13，列表行 28，表格行 42，外围留白加大 |

行距、内边距、字号三者一起动。来自固定栅格的留白显得从容，来自不合身栅格或拉伸卡片的留白显得未完成。按账户现有数据定区块大小。

## 10. 空、零、加载、错误

- 真零正常显示（¥0、0.00%）；缺失用小号灰色短横，不用大号“--”。
- 计数随当前视图/筛选重算。
- 空区块保留框和标题，一句话跨整块（`grid-column: 1 / -1`），1px 虚线框、圆角 8、约 38px 高；空图表照画零线。
- 红色是信号：每对象至多一个红色标记。
- 首次使用：保留框架，第一个操作放在数据将出现处。
- 加载：最终布局里每个值换成同尺寸平灰条，行距不变，标签表头立即显示，无闪光渐变，数据到达不跳动；刷新时保留旧值并更新新鲜度戳。
- 错误：在失败块内一句话说明失败与最后正常时间（“部署列表加载失败，最后更新 09:14”）+ 文字“重试”；不用全屏横幅，负色只在小图标或 pill。

## 11. 手机端

- 侧栏折为 48px 顶栏（屏幕名 + 菜单打开全屏抽屉，至多一个操作）或 4–5 项底部栏；侧栏不得占 >30% 宽。
- 边距 16–20px，触控 ≥44px，数据 14px，副行 ≥12px；标题 20–24px，其他标题操作收进 kebab。
- 筛选收成一行 chip 或抽屉，标签页行内横滚，页面不横滚；首行列表在屏幕上 60% 内；图表上方至多一行控件。
- KPI 改 2 列网格（偶数，奇数时末格通宽）或左标签右数值列表，不挤 4 列。
- 图表通宽 160–200px 高，3–4 个 x 标签，图例在上；y 刻度独立通道不压线。
- <640px 表格变两行列表：首行标识 + 关键数字，次行 13px 灰色其他字段，操作在右；字段只移不删。必须保留的表格在自身框内横滚并固定首列。
- 平板 641–1100px：侧栏折到顶栏，表保留 4–5 列。
- 带操作的块上移成一行摘要；多窗格一次一个区域；设置标签列堆在面板上；右栏移到主列下。

## 12. 生成式仪表盘典型破绽

见到即改：深色/染色侧栏 + 彩色当前项；“欢迎回来 👋”；KPI 卡圆底图标、绿色 +12.5%、迷你折线、36–48px 品牌色数字；渐变面积 + 平滑曲线 + 圆点；彩虹配色；单系列图例；粗甜甜圈扇区标签；大圆角 + 边框 + 大阴影；全大写斑马表；左对齐比例数字；饱和 chip 白字；强调色铺满按钮；搜索 + 铃铛 + 头像的空顶栏；占位人名与虚荣总数；短列表分页；孤格与拉伸卡；霓虹、发光、玻璃；套件默认脸（Inter + #f8f8f8 + 白卡、数据无色相）；空图表插画。紫/靛、奶油配赤陶为原作者偏好，仅作默认回避。

## 13. 检查问题

1. 最大的块与数字是否回答屏幕的问题且最先被读到？
2. 各块是否共享边线，无死带、孤格、拉伸空白带？
3. 颜色是否只在数据、状态和唯一主操作，主数据带色相？
4. 数字是否对得上、逐位对齐，重复事实一致，相对数字有基准？
5. 零像零、缺失是短横，计数徽标只在待处理队列？
6. 图例与标记一致，标签不撞线？手机上导航折叠、每块仍回答问题？
