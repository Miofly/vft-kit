## Monorepo: dependencies.md 适配

当项目为 monorepo 时，全局 `dependencies.md` 包含两层依赖：

1. **包间依赖**（主要）: workspace 依赖、构建产物复制、运行时引用
2. **关键第三方依赖**: 按包分组列出

模板在"内部模块依赖"段落改为"包间依赖"，图中节点为包名。每个包的内部依赖由包级 `overview.md` 覆盖。
