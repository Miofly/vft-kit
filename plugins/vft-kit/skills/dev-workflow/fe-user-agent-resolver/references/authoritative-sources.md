# 权威来源与网查规则

本文件约束消费者型号与发布日期的网查确认流程与 `data/device-models.json` 的收录标准。

## 1. 什么时候网查

- 脚本输出 `flags.needs_web_lookup=true` 且用户关心消费者型号时；或 `device.release_date` 为 null 且用户关心发布日期时。
- iOS 设备（UA 无机型）、缩减 UA（机型已抹除）、爬虫 UA 一律不网查。

## 2. 检索纪律

- **只提交型号代码与品牌线索**（如 `NOH-AN00 华为 官网`），**绝不提交完整 UA**——UA 可能携带用户环境指纹。
- 优先站点检索厂商官方域名：

| 品牌 | 官方域名 |
| --- | --- |
| 华为 | consumer.huawei.com |
| 荣耀 | hihonor.com |
| 小米/Redmi | mi.com |
| OPPO | oppo.com |
| 一加 | oneplus.com |
| vivo/iQOO | vivo.com.cn |
| realme | realme.com |
| 三星 | samsung.com |
| 苹果 | support.apple.com |
| 谷歌 | store.google.com |

- 允许的次级来源：工信部进网许可（jwxk.miit.gov.cn）、各品牌官方商城页、官方规格/支持页。
- 第三方数据库（GSMArena、ZOL 等）只能作线索，不能单独作为确认依据。

## 3. 确认标准

同时满足才可判定 confirmed：

1. 权威页面上**同时出现**完整型号代码与消费者型号名称；
2. 品牌线索（UA 中的浏览器/HMSCore 等标记、型号前缀）与页面品牌不冲突；
3. 无其他权威来源给出相互冲突的名称。

不满足则如实输出：型号代码 + 未能从权威来源确认。同一代码对应多个名称时列出候选，不要择一。

发布日期同理：以厂商官网发布页/规格页、官方新闻稿或工信部进网许可给出的上市时间为准，精确到年月（YYYY-MM，取中国大陆上市时间）；第三方设备库的日期只能作线索。未经权威来源确认的日期如实说明未确认，不要凭型号代码或发布节奏推测年份。

## 4. 映射表收录标准

- 键为大写型号代码，值含 `brand`、`name` 与 `released`（上市年月，YYYY-MM）。
- 每条新增都必须走过第 3 节的确认标准，`released` 与型号名同源核实。
- 有疑问的条目宁缺毋滥——映射表给错一次，就是把 certain 的牌子砸了。
