# Font sources

The bundled WOFF2 files are subsets derived from the following Google Fonts sources. They remain licensed under the SIL Open Font License 1.1 in `OFL-1.1.txt`.

| Bundled files | Family | Upstream source |
|---|---|---|
| `bagel-fat-one-ui.woff2` | Bagel Fat One | https://github.com/google/fonts/tree/main/ofl/bagelfatone |
| `fraunces-ui.woff2`, `fraunces-italic-ui.woff2` | Fraunces | https://github.com/google/fonts/tree/main/ofl/fraunces |
| `ma-shan-zheng-common-cn.woff2` | Ma Shan Zheng | https://github.com/google/fonts/tree/main/ofl/mashanzheng |
| `space-mono-regular-ui.woff2`, `space-mono-bold-ui.woff2` | Space Mono | https://github.com/google/fonts/tree/main/ofl/spacemono |
| `zcool-kuaile-ui.woff2` | ZCOOL KuaiLe | https://github.com/google/fonts/tree/main/ofl/zcoolkuaile |

These subsets reproduce the reference UI's typography but do not contain every Unicode glyph. Keep a readable Chinese fallback and generate a new licensed subset from the upstream font when target copy uses missing glyphs.
