# 后台管理系统类需求专项检查

基于历史需求评审问题提炼的后台管理系统专项检查点，配合通用检查（req-quality-check）使用。

## 执行说明

1. 先通读需求文档，理解后台系统的使用角色和核心功能
2. **逐张读取需求中的图片**（后台原型截图、列表 / 搜索 / 导入 / 导出 / 审核界面、字段配置表、权限矩阵截图等），用 Read 工具识别其中的字段定义、表单校验、按钮权限、列表筛选项、操作流程、状态流转等。**后台系统的字段含义、操作权限、校验规则经常以表格或原型图形式给出**，必须把图片信息纳入下方各项检查；仅依据正文文字判断"未提及"会误判为缺失
3. 按以下各维度逐项检查，结合实际需求判断是否适用
4. 检查结果标记：✅已提供 / ❌未提供（需补充）/ ➖不适用（说明原因）
5. 最后加载 `references/custom-checklist.md` 中的后台系统自定义检查项，一并执行

## 输出规则（与 req-review-agent 编排时遵守）

- **只输出有问题的检查项**：✅已提供 和 ➖不适用 的项一律不展示
- **去重**：本专项检查只关注后台管理系统独有的检查点；通用业务场景（页面交互/列表/输入框/登录等）已由 req-quality-check 业务检查表覆盖，本节不重复输出
- 若所有检查项均通过或不适用 → 整节不输出
- 直接给事实和建议，不写套话

## 内置检查点

### 一、权限与角色
| 检查项 | 检查内容 |
|--------|---------|
| 角色清单 | 系统使用的角色清单是否完整列出 |
| 操作权限矩阵 | 每个功能模块各角色的操作权限是否定义（增/删/改/查） |
| 数据权限 | 数据可见范围（如只能看自己创建的数据）是否说明 |
| 权限生效时机 | 权限变更的生效时机是否说明（实时/重新登录） |

### 二、列表与搜索
| 检查项 | 检查内容 |
|--------|---------|
| 搜索条件 | 支持的搜索/筛选条件是否完整 |
| 搜索逻辑 | 多条件搜索的逻辑关系（AND/OR）是否说明 |
| 模糊搜索 | 哪些字段支持模糊搜索是否说明 |
| 默认排序 | 列表默认排序规则是否说明 |
| 分页规则 | 每页条数默认值/可选值，是否显示总条数 |
| 空态文案 | 列表为空时的展示文案 |
| 必要字段 | 列表是否包含：唯一标识、创建时间、创建人、最后修改时间 |

### 三、新增与编辑
| 检查项 | 检查内容 |
|--------|---------|
| 必填/选填 | 所有字段的必填/选填状态是否明确标识 |
| 重复校验 | 新增时是否允许重复，重复判断依据是什么 |
| 默认值 | 各字段的默认值是否说明 |
| 保存反馈 | 保存成功/失败的提示文案是否定义 |

### 四、删除与状态变更
| 检查项 | 检查内容 |
|--------|---------|
| 危险操作确认 | 删除/下架/强制操作是否有二次确认弹窗 |
| 确认文案 | 确认弹窗的提示文案是否定义 |
| 级联影响 | 删除/变更对关联数据的影响是否说明 |
| 不可删除场景 | 哪些情况下禁止删除，提示文案是什么 |

### 五、批量操作
| 检查项 | 检查内容 |
|--------|---------|
| 批量上限 | 单次批量操作的数量上限是否说明 |
| 部分失败 | 批量操作部分失败时的处理和提示 |
| 进度反馈 | 批量操作是否有进度展示 |
| 操作结果 | 批量操作完成后的结果汇总（成功数/失败数/失败原因） |

### 六、数据导入
| 检查项 | 检查内容 |
|--------|---------|
| 文件格式 | 支持的导入文件格式是否说明 |
| 字段校验 | 各字段的校验规则是否完整定义 |
| 错误提示 | 导入失败时的错误定位和提示方式 |
| 重复处理 | 导入数据与已有数据重复时的处理策略（覆盖/跳过/报错） |
| 导入模板 | 是否需要提供导入模板下载 |

### 七、数据导出
| 检查项 | 检查内容 |
|--------|---------|
| 导出字段 | 导出文件包含哪些字段是否说明 |
| 数量上限 | 单次导出数据量上限是否说明 |
| 文件格式 | 导出文件格式是否说明（Excel/CSV） |
| 超量处理 | 超出导出上限时的提示方案（分批/异步导出） |

### 八、操作日志
| 检查项 | 检查内容 |
|--------|---------|
| 需记录操作 | 哪些操作需要记录操作日志是否说明 |
| 日志内容 | 日志需记录的字段：操作人/时间/操作内容/操作前后值 |
| 日志查询 | 操作日志是否需要提供查询入口 |

### 九、长耗时任务
| 检查项 | 检查内容 |
|--------|---------|
| 任务状态 | 任务状态流转是否完整（待处理/处理中/成功/失败） |
| 进度展示 | 任务处理进度是否有实时展示 |
| 失败重试 | 失败任务的重试方式是否说明（手动/自动） |
| 主子任务 | 主任务和子任务的页面设计是否均有说明 |

## 输出格式

以**问题驱动**方式输出本专项检出的问题（**不使用表格**），供 `req-review-agent` 汇入统一「问题清单」。单独使用时追加在通用检查报告之后。

- 只输出有问题的检查项；✅已提供、➖不适用一律不展示；无问题则整节省略。
- 每条问题：来源统一标 **📋知识库(后台系统专项)**，置信度 高/中/低，含 原文/现状、问题、建议改写。
