# 后台管理系统类 - 自定义扩展检查项

> 本文件用于扩展 req-check-admin-system 的检查点。
> 在此追加的检查项会在每次后台管理系统类需求评审时自动纳入检查范围。
>
> **如何新增检查项：**
> 在对应分类下按以下格式追加一行：
> `| 检查项名称 | 检查内容描述 | 适用场景（可选） |`
> 保存后，下次运行 /req-check-admin-system 或 /req-review-agent 时自动生效。

---
