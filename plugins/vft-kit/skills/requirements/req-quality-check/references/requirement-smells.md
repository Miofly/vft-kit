# 需求异味词法检查表（Requirement Smells）

来源：Femmer 等《Rapid Quality Assurance with Requirements Smells》(2016) + ISO/IEC/IEEE 29148，结合中文需求场景本地化。

> **用途**：确定性的词法级检查，命中即为问题。区别于"推理类"问题——这类命中是**确定性的**，故：
> - **来源标记**：🔤规则命中(词法异味)
> - **置信度**：默认 **高**（词面证据明确）
> - 每条命中必须**引用原文** + 给**建议改写**
>
> **注意**：词法命中是"疑似"信号，需结合上下文判断是否真的构成问题（如需求已在别处给出精确定义，则不算异味）。命中但上下文已消解歧义的，不输出。

---

## 一、模糊副词 / 形容词（无可验证基准）

**异味词**：尽量、尽快、快速、迅速、及时、友好、合理、适当、适度、大量、少量、若干、部分、一些、灵活、高效、稳定、流畅、良好、清晰、简洁、美观、方便

**为何是问题**：无法量化，不同人理解不同，不可验证。

**示例 → 建议改写**：
- ❌"系统应尽快响应" → ✅"接口响应时间 ≤ 500ms（95 分位）"
- ❌"页面加载要流畅" → ✅"首屏加载 ≤ 2s，滑动帧率 ≥ 50fps"
- ❌"支持大量并发" → ✅"支持峰值 QPS ≥ 5000"

---

## 二、最高级 / 比较级（无基准对象）

**异味词**：最优、最好、最快、最大、最小、最高、尽可能、更快、更好、更多、越…越…

**为何是问题**：缺少比较基准与目标值，无法验收。

**示例 → 建议改写**：
- ❌"以最优方式展示" → ✅明确排序/展示规则
- ❌"尽可能多地展示资源" → ✅"单页展示 20 条，下拉加载更多"

---

## 三、否定式 / 排除式需求（缺正向可验证描述）

**异味模式**：不允许…、不能…、禁止…、除…之外（且未给出正向行为）

**为何是问题**：只说"不做什么"，未说"应做什么"，边界不清，难以验证。

**示例 → 建议改写**：
- ❌"不允许非法输入" → ✅"仅允许输入 6-20 位字母数字，其他字符实时过滤并提示"

---

## 四、指代不清的代词 / 指示词

**异味词**：其、该、它、此、这、那、上述、前者、后者、相应的、对应的（指代对象不唯一或跨段落）

**为何是问题**：指代对象不明，易产生二义。

**示例 → 建议改写**：
- ❌"用户下单后，其状态变更" →（"其"指订单还是用户？）✅"用户下单后，**订单**状态变更为待支付"

---

## 五、漏洞措辞 / 逃避性表达（Loopholes）

**异味词**：原则上、一般情况下、通常、视情况、如有必要、必要时、酌情、尽可能、大致、大概、约、左右、等等、以及其他、诸如此类

**为何是问题**：给实现留下随意发挥空间，需求边界不可控。

**示例 → 建议改写**：
- ❌"原则上不超过 3 次" →（"原则上"意味着有例外？）✅明确"最多 3 次；超过则锁定 30 分钟"
- ❌"展示销量、评分等等" → ✅穷举需展示的字段

---

## 六、未定 / 占位措辞（TBD）

**异味词**：TBD、待定、待补充、待确认、后续补充、暂定、稍后、TODO、xxx、待运营提供、待接口方确认

**为何是问题**：需求信息缺口，评审时即为未闭环项。

**处理**：标出所有未定项，要求评审前确认或明确谁在何时补充。

---

## 七、口语化 / 主观判断词

**异味词**：应该、可能、也许、大概、感觉、看起来、差不多、基本上、几乎、貌似

**为何是问题**：表达不确定，需求方自己都未拍板。

**示例 → 建议改写**：
- ❌"点击后应该跳转到详情页" →（"应该"=不确定？）✅"点击后跳转到详情页"

---

## 八、连接词歧义（and/or 混用）

**异味模式**：A 和/或 B、A、B 等、既…又…（未说清是并列全选还是任选）

**为何是问题**："和/或"导致逻辑关系不明，影响实现分支。

**示例 → 建议改写**：
- ❌"满足实名和/或会员" → ✅明确"同时满足实名**且**会员" 或 "满足实名**或**会员任一"

---

## 使用说明

1. 逐条扫描需求正文与图片文字，命中异味词后**结合上下文确认**是否真构成问题。
2. 命中且构成问题的，作为一条问题输出：🔤规则命中(词法异味) + 置信度:高 + 原文 + 建议改写。
3. 优先级：多数词法异味属 🟢 低 / 🟡 中（完善性/理解性）；若异味出现在关键计费/权益/核心流程描述上，升为 🔴 高。
4. 本表支持扩展：新增异味词按对应分类追加即可。
