
## 多任务并行（硬规则）

- 一次请求含多个可独立完成的子项（多个段落、文件、模块、平台、调研方向）时，**必须**拆成多个后台子 agent 同时做，一个子项一个任务（上限约 8，速度优先于省 token）；不得一项项串行做，也不等用户说「开多个任务」。主控只写任务书、验收、合并。
- 按写入文件切分：同一文件不得有两个任务同时写；同一文件的多个子项也拆开，各任务只返回改后文本，由主控一次合入。有先后依赖的（先写去处再删原处、先改源再同步）由主控排序。
- 任务书一次写全：目标、只能改的文件、备份位置、验收命令、能否提交、报告直接回复。只有几条命令就能做完、或必须连续判断的小活，才由主控自己做。
